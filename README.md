# Hangman Game

## About
A simple text-based Hangman game developed using Python. The player guesses a hidden word one letter at a time.

## Features
- Guess the hidden word
- One-letter-at-a-time guessing
- Maximum 6 incorrect guesses
- Simple console input and output
- Random word selection

## Technologies Used
- Python
- Random module
- While loop
- If-else conditions
- Strings
- Lists

## How to Run
1. Download or clone this repository.
2. Open `hangman game.py` in Python or VS Code.
3. Run the program.
4. Enter letters to guess the hidden word.
